# Hugging Face Agents Course — локальный ридер

Рабочая локальная версия материалов из [официального репозитория](https://github.com/huggingface/agents-course). Все 76 страниц доступны на русском: 51 дополнительный перевод закрывает отсутствовавшие языковые версии, а 12 начальных уроков локально актуализированы относительно английского текста и новой практики. Английские оригиналы сохранены. Ридер не исполняет учебные Python/JavaScript-примеры.

## Клонирование репозитория

Официальные исходники курса подключены как Git submodule и закреплены на проверенной ревизии. Поэтому при первом клонировании используйте `--recurse-submodules`:

```bash
git clone --recurse-submodules https://github.com/ImportAd/huggingface_agents_course_ru.git
cd huggingface_agents_course_ru
```

Если репозиторий уже был клонирован без этого параметра:

```bash
git submodule update --init --recursive
```

## Запуск на Windows

Установите Git и Node.js 24 LTS с официальных страниц [Git for Windows](https://git-scm.com/downloads/win) и [Node.js](https://nodejs.org/en/download). Минимальная поддерживаемая версия Node.js — 22.12. После установки откройте PowerShell в папке репозитория и выполните:

```powershell
npm.cmd ci
npm.cmd run dev
```

Откройте **http://127.0.0.1:5173**. Это localhost вашего компьютера. Адрес `http://localhost:5173` также можно использовать, если в вашей системе localhost корректно разрешается в IPv4. Сервер слушает только локальный адрес. Остановка — `Ctrl+C` в терминале.

При следующих запусках достаточно перейти в папку репозитория и выполнить `npm.cmd run dev`. Команда `npm.cmd ci` нужна заново после изменения `package-lock.json` или на новом компьютере.

Если `node`, `npm` или `git` не найдены после установки, перезапустите PowerShell или VS Code и проверьте:

```powershell
node --version
npm.cmd --version
git --version
```

Если PowerShell блокирует `npm.ps1`, используйте `npm.cmd ci` и `npm.cmd run dev`. Менять политику выполнения PowerShell не требуется.

## Запуск на Ubuntu

Установите Git, curl и Node.js 24 через `nvm`:

```bash
sudo apt update
sudo apt install -y git curl
curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.40.8/install.sh | bash
source ~/.bashrc
nvm install 24
node --version
npm --version
```

Затем клонируйте репозиторий командами из раздела выше и запустите ридер:

```bash
npm ci
npm run dev
```

Откройте **http://127.0.0.1:5173**. Остановка — `Ctrl+C`. При следующих запусках достаточно `cd huggingface_agents_course_ru && npm run dev`.

## Доступ из домашней сети

Чтобы запустить ридер на одном компьютере и открыть его с другого устройства в той же домашней сети, используйте:

```bash
npm run dev:lan
```

Узнайте локальный IPv4-адрес сервера командой `ipconfig` в Windows или `hostname -I` в Ubuntu и откройте на другом устройстве `http://<IP-адрес>:5173`. Например: `http://192.168.1.50:5173`. В Windows при первом запуске разрешите Node.js доступ только для частной сети. Этот режим публикует ридер во всей локальной сети, поэтому используйте его только в доверенной домашней сети.

## Что находится в папке

```text

  course-translations/

    titles.json                   русские названия разделов оглавления
    README.md                     правила перевода и словарь терминов
  local-course-reader/

    requirements.txt              зависимости Python
  package.json                    команды из корневой папки, npm workspaces
  package-lock.json               зафиксированные зависимости
```

Исходные материалы — `course-source/units/{en,ru-RU}/**/*.mdx`, дополнительные переводы и локальные актуализации — `course-translations/ru-RU/**/*.mdx`. Файлы в `public/course` генерируются заново при запуске и сборке; редактировать их не нужно. Скачивание MDX текущего текста доступно под каждой статьёй. Checkout `course-source` остаётся отдельным submodule со своим origin и историей Git.

## Чтение курса

- Оглавление построено по официальному английскому `_toctree.yml`. Русское оглавление добавляет переведённые названия и дополнительные страницы; найденные MDX вне оглавления тоже включаются.
- В режиме **RU** локальная версия из `course-translations/ru-RU/<путь>.mdx` заменяет устаревший официальный RU или дополняет отсутствующий перевод. Для остальных путей используется официальный `course-source/units/ru-RU/<путь>.mdx`, затем английский оригинал. Если после обновления появится новый урок без перевода, включится EN fallback с пояснением и значком EN в оглавлении.
- Первый практический цикл переработан для Ubuntu: ручной вызов инструмента и агент на LangGraph используют локальную модель `qwen3:4b-instruct` через Ollama. Готовый проект находится в [first-local-agent](first-local-agent/README.md). Hugging Face Space и API-токен для упражнения не нужны.
- Локальные переводы помечены под статьёй. Переведены повествование, заголовки, таблицы, подписи, вопросы и пояснения. Код, комментарии и промпты внутри блоков кода, названия API, изображения и внешние сервисы сохранены в оригинале. Подробнее — [правила и словарь перевода](course-translations/README.md).
- В режиме **EN** используются исключительно `units/en`. Русские страницы, не имеющие английской версии, скрываются в оглавлении EN. При прямом переходе на такую страницу показывается ссылка на русский текст.
- Поиск проверяет русские/английские названия, путь урока и названия разделов. Кнопки внизу идут в порядке оглавления и не зависят от поискового фильтра.
- Последний урок, язык и настройка оглавления сохраняются в localStorage браузера. При входе через `/` открывается последний урок. Явный URL имеет приоритет.
- Пример прямого адреса: `http://127.0.0.1:5173/ru/unit1/what-are-llms`. Обновление вкладки работает: Vite возвращает оболочку приложения для вложенных маршрутов.
- Относительные и полные ссылки на существующие страницы курса становятся локальными и сохраняют выбранный режим языка и якорь. Внешние материалы открываются в отдельной вкладке.

## Поддержка Markdown и MDX

Используется Vite + React. Node-генератор преобразует Markdown через unified/remark, GFM и rehype. HTML очищается от исполняемых тегов и обработчиков, код подсвечивается highlight.js. Каждая статья загружается отдельным локальным JSON; сервер Hugging Face для текста не нужен.

Поддержаны заголовки, жирный/курсивный текст, списки, цитаты, таблицы Markdown и HTML, inline/fenced code, изображения, `figure`/`figcaption`, `details`/`summary`, видео и аудио. Длинный код и таблицы прокручиваются внутри статьи, код можно копировать.

Местные аналоги компонентов:

| Исходная конструкция | Поведение |
| --- | --- |
| `Question` | Выбор ответа, проверка, исходные пояснения; поддерживаются несколько правильных ответов |
| `CourseFloatingBanner` | Ссылки на исходные блокноты и помощь |
| `hfoptions` / `hfoption` | Переключаемые вкладки; все варианты кода сохранены, есть клавиатурная навигация |
| `[!TIP]`, `[!NOTE]`, `[!WARNING]`, `[!IMPORTANT]`, `[!CAUTION]` | Информационные блоки |
| `Tip`, `Note`, `Warning`, `Caution`, `Important` | Аналогичные блоки; запасная поддержка будущих MDX |
| `[[anchor]]` | Стабильный якорь заголовка |
| `iframe` | Кнопка загрузки видео/демонстрации и ссылка для открытия отдельно |
| Неизвестный компонент | Упрощённый блок с исходным тегом/параметрами и вложенным содержимым |

Атрибуты компонентов читаются как статические данные JSON5, без `eval` и без исполнения JSX. Если отдельный компонент не поддержан, он сохраняется в упрощённом виде. Если изменённый в будущем файл целиком не удастся разобрать, будет доступен полный исходный текст; остальные страницы продолжат работать. Диагностика импорта хранится в `public/course/manifest.json`.

## Обновление курса

```bash
npm run update-course
```

Команда выполняет `git pull --ff-only` внутри `course-source`, затем пересобирает страницы и оглавление. Если папки нет, клонирует официальный репозиторий. При незакоммиченных изменениях скрипт останавливается и сохраняет их; сбросов и удаления файлов нет.

Локальные переводы и актуализации хранятся вне checkout и не перезаписываются при обновлении. Если английский исходник изменится, сравнение SHA-256 отметит соответствующий русский текст как требующий сверки; уведомление появится над статьёй и в `translationDiagnostics` манифеста. Аналогично обнаруживаются изменения русского текста после проверки.

После обновления обновите вкладку браузера. Dev server также следит за изменениями MDX, оглавления и локальных переводов. Для production-версии повторите `npm run build`. Можно выполнить `git -C course-source pull --ff-only` вручную, после чего перезапустить `npm run dev`.

## Сборка и проверки

```bash
npm run build
npm test
npm run test:browser
```

Браузерные тесты используют установленный Google Chrome через Playwright; тестовый dev server запускается автоматически, если он ещё не работает. Чтобы использовать другой браузер, измените `channel` в `local-course-reader/playwright.config.js` (например, `msedge` для Edge). Снимок интерфейса — `local-course-reader/test-results/reader-desktop.png`.

Production-версия:

```bash
npm run build
npm run preview
```

Откройте **http://127.0.0.1:4173**. Папка `dist` содержит приложение, тексты, оригинальные MDX, лицензию и используемые локальные assets. Её можно перенести на другой компьютер и обслуживать статическим сервером с SPA fallback на `index.html`. Двойной щелчок по `dist/index.html` через `file://` не заменяет HTTP-сервер.

## Интернет и ограничения

- Все тексты RU/EN и локальные тесты `Question` работают без внешнего интернета после установки и генерации. В текущем checkout изображения находятся по внешним URL Hugging Face. Для них, видео, Spaces, Colab, API, авторизации и получения сертификатов нужен интернет; эти сервисы остаются внешними.
- Если изображение недоступно, появляется подпись со ссылкой на источник. Если asset существует в самом репозитории, генератор предпочитает локальный файл и включает его в сборку.
- Для iframe доступность и вход в аккаунт зависят от внешнего сайта и настроек cookies. При проблемах используйте «Открыть отдельно». Ридер не выдаёт сертификаты и не отправляет задания сам.
- Для 12 начальных страниц проверена актуальность относительно английской ревизии и локальной практики на 23 сентября 2026 года. Остальные официальные русские материалы могут потребовать отдельной редакторской актуализации; внешний API и интерфейсы сервисов со временем меняются.
- Текущий снимок содержит 76 уникальных страниц: 74 EN и 76 RU; 51 страница переведена локально, 12 официальных русских страниц заменены локально актуализированными версиями, два файла есть только на русском. Ревизия источника: `b3946b1d09d29c65736e219d48a8a736a2c52154`.

## Частые проблемы

| Симптом | Решение |
| --- | --- |
| `node` / `npm` / `git` не найдены | Установите программы, перезапустите VS Code, проверьте PATH |
| `npm.ps1 cannot be loaded` | Используйте `npm.cmd` вместо `npm` |
| `EBADENGINE` | Обновите Node.js до 24 LTS |
| Нет `course-source/units/en` | Выполните `npm run update-course` |
| Порт 5173 занят | Откройте уже запущенный ридер или остановите его `Ctrl+C`; для другого порта: `npm run dev --workspace local-course-reader -- --port 5174` |
| `localhost` не открывается | Используйте `http://127.0.0.1:5173`; в этой Windows-среде IPv6 loopback возвращал `EACCES` |
| Ошибка установки пакетов или `git pull` | Проверьте интернет, прокси и доступ к npmjs.org / github.com; повторите команду |
| Обновление остановлено из-за изменений | Сохраните свои изменения в `course-source` через Git; скрипт не перезаписывает их автоматически |
| Старый текст в preview | Повторите `npm run build`, затем обновите вкладку |
| Нет изображений/видео | Проверьте доступ к их внешним источникам; сам текст курса доступен локально |
