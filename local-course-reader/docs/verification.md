## Что проверяют тесты

Контентные проверки проходят по всем 150 MDX (99 исходных + 51 перевод): каждый включён в оглавление ровно один раз как страница/языковая версия, текст скопирован без изменений из соответствующего источника, каждый fenced code block сохранён целиком, виджеты сохранены, локальные ссылки ведут на существующие уроки, нет полных fallback-страниц. EN сохраняет официальный порядок; отдельно проверены вложенное оглавление, RU-only и страницы вне metadata.

Для всех 51 переводов дополнительно сверены SHA-256 оригинала и перевода, блоки кода, HTTP(S)-адреса, якоря заголовков всех шести уровней, идентификаторы вкладок, параметры баннеров, число вариантов и признаки правильных ответов. Пояснения тестов содержат русский текст. Проверены отсутствие служебных заполнителей и русские названия групп оглавления. Поиск длинных английских фрагментов вне кода в отрендеренном тексте не выявил оставленного без перевода повествования. Это структурные проверки; они не заменяют экспертную лингвистическую рецензию.

Для 12 актуализированных страниц отдельно проверены SHA-256 английского источника и русского текста, источник отображения в манифесте, отсутствие старого шаблона Space в первом практическом уроке, наличие инструкций Ubuntu/Ollama/LangGraph и копирование проекта в production-сборку. Подробные находки — в `content-freshness-audit.md`.

Синтетический пример проверяет неизвестные компоненты, статический разбор JSX без исполнения выражений, сохранение вложенного Markdown, Tip, явные якоря и удаление исполняемого HTML.

## Ограничения проверки

Внешняя авторизация, отправка заданий и выдача сертификатов не проверялись: это действия во внешних сервисах. Настоящий ответ `qwen3:4b-instruct` не запускался, потому что весов Ollama в среде разработки нет; интерфейс графа и полный цикл проверены детерминированной имитацией модели. Команды и API сверены с первичной документацией. В текущем checkout нет локальных изображений: браузер показывает fallback при заблокированной сети.

В этой системе привязка сервера к IPv6 `::1` давала `EACCES` при клиентском подключении. Скрипты запускают сервер на IPv4 `127.0.0.1`; после исправления адреса `localhost:5173` и `127.0.0.1:5173` оба вернули HTTP 200.
