# Проверка актуальности начальных русских уроков

Проверено 23 сентября 2026 года. Официальный репозиторий `huggingface/agents-course` находился на ревизии `b3946b1d09d29c65736e219d48a8a736a2c52154`; удалённая ветка `main` указывала на ту же ревизию. Checkout `course-source` не изменялся.

## Объём работы

Скрипт `scripts/audit-official-ru.mjs` сопоставил 23 официальных русских MDX с английскими страницами: количество заголовков и блоков кода, ссылки и примерный объём текста. Это обнаружило пропущенные разделы и помогает повторять аудит после обновления исходника. Структурное сравнение само по себе не подтверждает актуальность фактов, поэтому инструкции, связанные с облачными сервисами и библиотеками, были дополнительно сверены с первичной документацией.

Локально актуализированы 12 страниц:

- Unit 0: введение и подготовка к курсу.
- Unit 1: введение, определение агента, LLM, инструменты, рассуждение, действия, ручной цикл агента, первый агент, итоговый тест и заключение.

Остальные главы не перерабатывались в рамках этого этапа. Существующие 51 локальный перевод и английские оригиналы сохранены.

## Основные находки

- В старом русском введении оставался дедлайн 1 июля 2025 года, тогда как английская страница говорит, что дедлайна нет.
- В официальное английское введение в работу уже добавили локальный вариант с Ollama, а в русском переводе этого раздела не было.
- Русский урок о первом агенте вёл в шаблон Hugging Face Space и использовал `InferenceClientModel`. На текущем Hugging Face создание вычислительных Gradio/Docker Spaces связано с планом аккаунта, а бесплатный пользователь Inference Providers получает небольшой ежемесячный кредит. Поэтому этот путь нельзя считать устойчивым бесплатным упражнением.
- В русском уроке о рассуждении отсутствовали отдельные разделы про Chain-of-Thought, пример ReAct и их сравнение.
- В русском определении агента отсутствовала таблица уровней агентности и был потерян заголовок примера чат-бота.
- В русском уроке об инструментах отсутствовал новый раздел про MCP.

## Новая практическая линия

Упражнение теперь состоит из двух связанных уроков и каталога `first-local-agent`:

1. `manual_agent.py` показывает цикл напрямую через локальный API Ollama: модель предлагает инструмент, Python проверяет и выполняет его, результат возвращается как наблюдение.
2. `agent.py` реализует тот же цикл графом LangGraph: узел модели, `ToolNode`, условный переход и ограничение числа итераций.
3. Используются два безопасных учебных инструмента без внешних API: текущее время по IANA timezone и умножение целых чисел.
4. `test_agent.py` проверяет инструменты и оба цикла с имитацией модели. Для тестов не нужны Ollama и загрузка весов.

Команды установки Ollama сверены с `https://docs.ollama.com/linux`; API `ChatOllama.bind_tools` — с `https://docs.langchain.com/oss/python/integrations/chat/ollama`; устройство графа — с `https://docs.langchain.com/oss/python/langgraph/quickstart`; модель и размер загрузки — с `https://ollama.com/library/qwen3:4b-instruct`. Состояние тарифов сверено с `https://huggingface.co/docs/hub/spaces-overview` и `https://huggingface.co/docs/inference-providers/pricing`.

## Контроль дальнейших изменений

`course-translations/adaptations.json` хранит SHA-256 английского оригинала и локально актуализированного текста. Генератор помечает страницу, если изменился оригинал или проверенная локальная версия. В ридере такие страницы подписаны как «Локально обновлённый русский урок».

После обновления официального репозитория следует запустить `node scripts/audit-official-ru.mjs`, генератор и тесты, затем содержательно пересмотреть страницы из `translationDiagnostics`. Изменение хеша фиксирует необходимость проверки, но не заменяет редакторскую оценку.
