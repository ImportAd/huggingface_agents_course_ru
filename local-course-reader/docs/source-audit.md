# Исследование исходников

Источник: https://github.com/huggingface/agents-course, ветка main. Исходники остаются отдельным git checkout в `../course-source`.

На момент первого импорта обнаружены 74 английских и 25 русских MDX-файлов. Два русских файла не имеют английской версии. Порядок задают `units/en/_toctree.yml` и `units/ru-RU/_toctree.yml`. Основной порядок берётся из EN; RU дополняет его названиями и дополнительными страницами. Файлы вне оглавления также включаются автоматически.

Изучены Unit 0 introduction/onboarding, Unit 1 introduction/what-are-llms/tools/quiz1, Unit 2 smolagents/code_agents, Unit 3 agentic-rag/introduction/invitees/tools и Unit 4 hands-on. Сканирование проведено по всем EN/RU файлам вне блоков кода.

Обнаруженные конструкции:

| Конструкция | Локальное представление |
| --- | --- |
| `Question choices={[...]}` | Интерактивный тест, исходные ответы, признаки correct и пояснения |
| `CourseFloatingBanner notebooks={[...]}` | Ссылки на блокноты и помощь |
| `hfoptions` / `hfoption id="..."` | Вкладки с сохранением каждого варианта кода |
| `> [!TIP]`, NOTE, WARNING и др. | Информационные блоки |
| `[[anchor]]` в заголовках | Именованные HTML-якоря |
| `details` / `summary` | Раскрываемые примеры, включая подсвеченный код |
| `figure` / `figcaption`, HTML-таблицы | Семантический HTML |
| `iframe` | Встраивание по нажатию, ссылка на внешний ресурс |
| Markdown-таблицы, fenced code | GFM и подсветка highlight.js |

Встречаются незакрытые HTML void-теги `img`, относительные ссылки (`./tools`, `../../unit1/tutorial`), абсолютные ссылки курса с языком и без него, специальные токены LLM внутри inline/fenced code. Прямой строгий JSX/MDX compile здесь требует лишних исправлений источника. Поэтому используется Markdown/HTML-конвейер с отдельным разбором статических атрибутов компонентов (без исполнения JavaScript).

В checkout нет растровых/векторных изображений или видео: изображения преимущественно находятся в датасете `agents-course/course-images` на Hugging Face. Генератор поддерживает относительные локальные assets и URL файлов этого GitHub-репозитория, если такие появятся.

Известная особенность источника: русская версия местами старее английской, в частности содержит прежние даты и страницы сертификата. Ридер сохраняет эти тексты без редакторских изменений. В режиме EN файлы, существующие только на русском, не подменяют английские страницы.
