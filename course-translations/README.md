# Русские переводы для локального ридера

Здесь находятся переводы отсутствовавших страниц и локальные актуализации официальных русских уроков. Они подготовлены ИИ-ассистентом по запросу владельца локального ридера и не являются официальным переводом Hugging Face.

Переведены все 51 недостающая страница: Unit 2 — 29, Unit 3 — 6, Unit 4 — 6, Bonus Unit 2 — 4, Bonus Unit 3 — 6. Вместе с 25 официальными русскими страницами это покрывает все 76 уроков локального курса.

Дополнительно актуализированы 12 начальных страниц Unit 0–1. Исправлены пропущенные фрагменты английской версии, устаревший дедлайн 2025 года, описание облачных ограничений и переходы к первому практическому заданию. Уроки `dummy-agent-library` и `tutorial` переработаны в единый локальный цикл на Ubuntu: сначала прямой вызов инструментов через Ollama, затем тот же граф на LangGraph. Сопровождающий код хранится в `../first-local-agent`.

Оригинальный источник: https://github.com/huggingface/agents-course, ревизия `b3946b1d09d29c65736e219d48a8a736a2c52154`. Лицензия исходных материалов — Apache-2.0, см. `../course-source/LICENSE`.

Перевод сохраняет обращение к читателю на «вы», дружелюбный учебный стиль, примеры с Альфредом, структуру и последовательность оригинала. Терминология уточняется без добавления новых утверждений и изменения содержания урока.

Исполняемый код, комментарии и строковые литералы внутри блоков кода сохранены на языке оригинала, чтобы примеры можно было сопоставлять с исходными блокнотами и запускать без изменения поведения. Объяснения вокруг кода, заголовки, таблицы, подписи, вопросы, варианты ответов и пояснения переведены. Изображения и внешние сервисы остаются оригинальными.

`manifest.json` фиксирует SHA-256 английского оригинала и 51 перевода, `adaptations.json` — английского оригинала и 12 актуализированных русских страниц. При изменении исходника генератор отмечает текст как требующий сверки. Добавленные к заголовкам явные якоря сохраняют работоспособность исходных ссылок после перевода.

Для редактирования используйте непосредственно MDX в `ru-RU`. После содержательной сверки с английским оригиналом обновите соответствующие SHA-256 и дату в нужном манифесте; простое изменение хешей не заменяет проверку. Генератор отдаёт приоритет локальной версии, если она есть, затем официальному русскому тексту и английскому оригиналу. `titles.json` дополняет русские названия групп оглавления.

В 12 адаптированных страницах Unit 0–1 устаревшие формулировки и первый практикум уже обновлены. Остальные 51 локальный перевод пока следует английскому источнику своей зафиксированной ревизии, включая его исторические формулировки. Например, в разных уроках Unit 4 источник использует «не менее 30%» и «более 30%». Такие расхождения в следующих модулях ещё предстоит проверить при их поэтапной актуализации.

## Словарь

| English | В переводе |
| --- | --- |
| agent / agentic | агент / агентный; agentic сохраняется в названии Agentic RAG |
| LLM / VLM | LLM / VLM; при необходимости: большая языковая / визуально-языковая модель |
| tool / tool calling | инструмент / вызов инструмента |
| function calling | вызов функций |
| reasoning | рассуждение |
| inference | инференс (получение предсказаний модели) |
| prompt / system prompt | промпт / системный промпт |
| workflow | рабочий процесс; Workflow в именах классов не переводится |
| state / node / edge | состояние / узел / ребро |
| retrieval / retriever | поиск / компонент поиска (retriever) |
| embedding | эмбеддинг (векторное представление) |
| RAG | RAG; генерация с дополнением контекста найденными данными |
| reranking | повторное ранжирование |
| grounding | опора на данные источников |
| observability / trace / span | наблюдаемость / трасса / span (отдельная операция трассы) |
| evaluation / benchmark | оценка / бенчмарк |
| fine-tuning | дообучение |
| guardrails | ограничения и защитные проверки |
| handoff | передача управления |
| checkpoint / checkpointer | контрольная точка / механизм сохранения контрольных точек |
| streaming | потоковая выдача |
| agent-as-a-tool | агент как инструмент |

Имена библиотек, API, моделей, классов, функций и параметров не переводятся. Различия смысла важнее буквального единообразия: например, retrieval в RAG — поиск данных, а не «извлечение» в смысле парсинга.
