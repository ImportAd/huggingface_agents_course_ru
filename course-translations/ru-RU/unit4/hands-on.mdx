# Практическое задание [[hands-on]]

Вы готовы приступить к созданию итогового агента. Посмотрим, как отправить его результаты на проверку.

## Датасет [[the-dataset]]

Датасет этой таблицы результатов состоит из 20 вопросов первого уровня, выбранных из **валидационной** выборки GAIA.

Вопросы отбирались по количеству инструментов и шагов, необходимых для ответа.

С учётом результатов на GAIA мы считаем разумной проверкой цель в 30% правильных ответов на вопросы первого уровня.

## Порядок работы [[the-process]]

Наверняка теперь вы спрашиваете: «Как начать отправлять ответы?»

Для этого раздела мы создали API, через который можно получать вопросы и отправлять ответы для оценки.
Вот краткое описание маршрутов; подробности можно попробовать в [интерактивной документации](https://agents-course-unit4-scoring.hf.space/docs):

* **`GET /questions`**: получить полный список отобранных вопросов.
* **`GET /random-question`**: получить один случайный вопрос из списка.
* **`GET /files/{task_id}`**: скачать файл, связанный с указанным идентификатором задачи.
* **`POST /submit`**: отправить ответы агента, вычислить результат и обновить таблицу участников.

Функция отправки сравнивает ответ с эталоном по принципу **ТОЧНОГО СОВПАДЕНИЯ**, поэтому тщательно составьте промпт! Команда GAIA опубликовала пример промпта [здесь](https://huggingface.co/spaces/gaia-benchmark/leaderboard). Для нашего курса не включайте в отправляемый текст слова «FINAL ANSWER»: агент должен возвращать только сам ответ, без дополнений.

🎨 **Сделайте шаблон своим!**

Чтобы показать работу с API, мы подготовили [базовый шаблон](https://huggingface.co/spaces/agents-course/Final_Assignment_Template).

Вы можете — и мы **очень советуем это делать** — менять, дополнять или полностью перестраивать его! Адаптируйте шаблон под собственный подход и идеи.

Для отправки шаблон подготавливает три элемента, необходимые API:

* **Username:** имя пользователя Hugging Face; здесь оно получается через вход в Gradio и служит для идентификации отправки.
* **Ссылка на код (`agent_code`):** URL кода вашего Hugging Face Space (`.../tree/main`) для проверки. Поэтому Space должен оставаться публичным.
* **Ответы (`answers`):** список ответов агента (`{"task_id": ..., "submitted_answer": ...}`), которые нужно оценить.

Для начала рекомендуем продублировать [шаблон](https://huggingface.co/spaces/agents-course/Final_Assignment_Template) в своём профиле Hugging Face.

🏆 Таблица результатов — [здесь](https://huggingface.co/spaces/agents-course/Students_leaderboard).

*Небольшое напоминание: эта таблица создана для удовольствия от участия! Мы понимаем, что результаты можно отправлять без полной проверки. Если появится слишком много высоких оценок без публичной ссылки на код, нам, возможно, придётся проверить, скорректировать или удалить некоторые записи, чтобы таблица оставалась полезной.*
В таблице будет ссылка на код вашего Space. Она предназначена для студентов курса, поэтому, получив результат, которым гордитесь, пожалуйста, оставьте Space публичным.
