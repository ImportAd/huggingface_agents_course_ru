# Что дальше? Какие темы стоит изучить? [[and-now-what-topics-i-should-learn]]

Агентный ИИ быстро развивается, и для создания интеллектуальных автономных систем важно понимать базовые протоколы.

Вот два стандарта, с которыми стоит познакомиться:

- **Model Context Protocol (MCP)**.
- **Agent-to-Agent Protocol (A2A)**.

## 🔌 Model Context Protocol (MCP) [[-model-context-protocol-mcp]]

**Model Context Protocol (MCP)** от Anthropic — открытый стандарт, который позволяет ИИ-моделям безопасно и удобно **подключаться к внешним инструментам, источникам данных и приложениям**, расширяя возможности и автономность агентов.

Представляйте MCP как **универсальный адаптер**, похожий на порт USB-C: он позволяет подключать модели к разным цифровым средам **без отдельной интеграции для каждой из них**.

MCP быстро набирает популярность в отрасли; его начинают внедрять крупные компании, включая OpenAI и Google.

- [MCP в Википедии](https://en.wikipedia.org/wiki/Model_Context_Protocol).

## 🤝 Протокол Agent-to-Agent (A2A) [[-agent-to-agent-a2a-protocol]]

Google разработала **протокол Agent-to-Agent (A2A)** как дополнение к Model Context Protocol от Anthropic.

MCP соединяет агентов с внешними инструментами, а **A2A связывает агентов друг с другом**, открывая путь к мультиагентным системам, совместно решающим сложные задачи.

📚 Подробнее об A2A:
- [Анонс A2A от Google](https://developers.googleblog.com/en/a2a-a-new-era-of-agent-interoperability/).
