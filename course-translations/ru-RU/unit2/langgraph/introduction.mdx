# Введение в `LangGraph` [[introduction-to-langgraph]]

<img src="https://huggingface.co/datasets/agents-course/course-images/resolve/main/en/unit2/LangGraph/LangGraph.png" alt="Обложка раздела 2.3"/>

Добро пожаловать в следующую часть нашего путешествия! Вы узнаете, **как создавать приложения** с помощью [`LangGraph`](https://github.com/langchain-ai/langgraph) — фреймворка для структурирования и оркестрации сложных рабочих процессов с LLM.

`LangGraph` позволяет создавать приложения, **готовые к production**, предоставляя инструменты **контроля** над потоком выполнения агента.
