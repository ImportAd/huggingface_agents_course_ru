# Основные элементы LangGraph [[building-blocks-of-langgraph]]

Чтобы создавать приложения на LangGraph, нужно понимать его ключевые компоненты. Рассмотрим основные элементы, из которых складывается приложение.

<img src="https://huggingface.co/datasets/agents-course/course-images/resolve/main/en/unit2/LangGraph/Building_blocks.png" alt="Основные элементы" width="70%"/>

Приложение LangGraph начинает работу с **точки входа**. В зависимости от хода выполнения управление переходит к одной функции или другой, пока не достигнет END.

<img src="https://huggingface.co/datasets/agents-course/course-images/resolve/main/en/unit2/LangGraph/application.png" alt="Приложение"/>

## 1. Состояние [[1-state]]

**Состояние (State)** — центральное понятие LangGraph. Оно содержит всю информацию, которая передаётся через приложение.

```python
from typing_extensions import TypedDict

class State(TypedDict):
    graph_state: str
```

Структуру состояния **определяете вы**, поэтому его поля нужно продумать так, чтобы в них были все данные для принятия решений!

> 💡 **Подсказка:** внимательно подумайте, какие сведения приложение должно сохранять между шагами.

## 2. Узлы [[2-nodes]]

**Узлы (Nodes)** — это функции Python. Каждый узел:
- Принимает состояние на вход.
- Выполняет операцию.
- Возвращает обновления состояния.

```python
def node_1(state):
    print("---Node 1---")
    return {"graph_state": state['graph_state'] +" I am"}

def node_2(state):
    print("---Node 2---")
    return {"graph_state": state['graph_state'] +" happy!"}

def node_3(state):
    print("---Node 3---")
    return {"graph_state": state['graph_state'] +" sad!"}
```

Например, узлы могут содержать:
- **Вызовы LLM:** генерация текста или принятие решений.
- **Вызовы инструментов:** взаимодействие с внешними системами.
- **Условную логику:** определение дальнейших шагов.
- **Участие человека:** получение данных от пользователя.

> 💡 **Примечание:** некоторые служебные узлы рабочего процесса, такие как START и END, предоставляет сам LangGraph.

## 3. Рёбра [[3-edges]]

**Рёбра (Edges)** соединяют узлы и задают возможные пути по графу:

```python
import random
from typing import Literal

def decide_mood(state) -> Literal["node_2", "node_3"]:
    
    # Often, we will use state to decide on the next node to visit
    user_input = state['graph_state'] 
    
    # Here, let's just do a 50 / 50 split between nodes 2, 3
    if random.random() < 0.5:

        # 50% of the time, we return Node 2
        return "node_2"
    
    # 50% of the time, we return Node 3
    return "node_3"
```

Рёбра бывают:
- **Прямыми:** всегда ведут из узла A в узел B.
- **Условными:** следующий узел выбирается по текущему состоянию.

## 4. StateGraph [[4-stategraph]]

**StateGraph** — контейнер, который объединяет весь рабочий процесс агента:

```python
from IPython.display import Image, display
from langgraph.graph import StateGraph, START, END

# Build graph
builder = StateGraph(State)
builder.add_node("node_1", node_1)
builder.add_node("node_2", node_2)
builder.add_node("node_3", node_3)

# Logic
builder.add_edge(START, "node_1")
builder.add_conditional_edges("node_1", decide_mood)
builder.add_edge("node_2", END)
builder.add_edge("node_3", END)

# Add
graph = builder.compile()
```

Его можно визуализировать!
```python
# View
display(Image(graph.get_graph().draw_mermaid_png()))
```
<img src="https://huggingface.co/datasets/agents-course/course-images/resolve/main/en/unit2/LangGraph/basic_graph.jpeg" alt="Визуализация графа"/>

Но главное — его можно запустить:
```python
graph.invoke({"graph_state" : "Hi, this is Lance."})
```
Результат:
```
---Node 1---
---Node 3---
{'graph_state': 'Hi, this is Lance. I am sad!'}
```
