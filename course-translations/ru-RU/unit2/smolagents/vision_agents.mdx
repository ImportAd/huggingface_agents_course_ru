# Агенты с визуальным восприятием в smolagents [[vision-agents-with-smolagents]]

> [!WARNING]
> Для примеров этого урока нужен доступ к мощной VLM. Мы тестировали их через API GPT-4o.
> В уроке <a href="./why_use_smolagents">«Зачем использовать smolagents»</a> рассмотрены альтернативы, поддерживаемые smolagents и Hugging Face. Загляните туда, если хотите попробовать другие варианты.

Визуальные возможности необходимы агентам для задач, выходящих за рамки обработки текста. Многие реальные задачи — например, просмотр веб-страниц или понимание документов — требуют анализа насыщенного визуального содержимого. К счастью, в `smolagents` встроена поддержка визуально-языковых моделей (VLM), благодаря которой агенты могут эффективно обрабатывать и интерпретировать изображения.

Представим, что Альфреду, дворецкому поместья Уэйнов, поручили проверять личности гостей вечеринки. Конечно, он может знать не всех прибывающих. Поможем ему агентом, который с помощью VLM ищет визуальную информацию о внешности гостей и проверяет их личность. Это позволит Альфреду обоснованно решать, кого впускать. Давайте реализуем пример!

## Передаём изображения в начале работы агента [[providing-images-at-the-start-of-the-agents-execution]]

> [!TIP]
> Код урока доступен в <a href="https://huggingface.co/agents-course/notebooks/blob/main/unit2/smolagents/vision_agents.ipynb" target="_blank">этом блокноте</a>, который можно запустить в Google Colab.

При таком подходе изображения передаются агенту сразу и сохраняются в `task_images` вместе с промптом задачи. Затем агент обрабатывает их в ходе своей работы.

Допустим, Альфред хочет проверить личности супергероев, пришедших на вечеринку. У него уже есть набор фотографий с предыдущих вечеринок с именами гостей. Получив изображение нового посетителя, агент может сравнить его с имеющимися данными и решить, стоит ли его впускать.

На этот раз на входе появился гость, которого Альфред подозревает в обмане: возможно, это Джокер, выдающий себя за Чудо-женщину. Нужно проверить его личность, чтобы не пропустить нежелательного посетителя.

Сначала загрузим изображения. Для простоты возьмём их из Википедии — но представьте, сколько у такого подхода применений!

```python
from PIL import Image
import requests
from io import BytesIO

image_urls = [
    "https://upload.wikimedia.org/wikipedia/commons/e/e8/The_Joker_at_Wax_Museum_Plus.jpg", # Joker image
    "https://upload.wikimedia.org/wikipedia/en/9/98/Joker_%28DC_Comics_character%29.jpg" # Joker image
]

images = []
for url in image_urls:
    headers = {
        "User-Agent": "Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36 (KHTML, like Gecko) Chrome/114.0.0.0 Safari/537.36" 
    }
    response = requests.get(url,headers=headers)
    image = Image.open(BytesIO(response.content)).convert("RGB")
    images.append(image)
```

Теперь агент определит, кто перед нами: супергерой — Чудо-женщина — или злодей Джокер.

```python
from smolagents import CodeAgent, OpenAIServerModel

model = OpenAIServerModel(model_id="gpt-4o")

# Instantiate the agent
agent = CodeAgent(
    tools=[],
    model=model,
    max_steps=20,
    verbosity_level=2
)

response = agent.run(
    """
    Describe the costume and makeup that the comic character in these photos is wearing and return the description.
    Tell me if the guest is The Joker or Wonder Woman.
    """,
    images=images
)
```

При моём запуске результат оказался таким. У вас он может отличаться, как мы уже обсуждали:

```python
    {
        'Costume and Makeup - First Image': (
            'Purple coat and a purple silk-like cravat or tie over a mustard-yellow shirt.',
            'White face paint with exaggerated features, dark eyebrows, blue eye makeup, red lips forming a wide smile.'
        ),
        'Costume and Makeup - Second Image': (
            'Dark suit with a flower on the lapel, holding a playing card.',
            'Pale skin, green hair, very red lips with an exaggerated grin.'
        ),
        'Character Identity': 'This character resembles known depictions of The Joker from comic book media.'
    }
```

Ответ показывает, что посетитель выдаёт себя за другого человека, — значит, мы можем не пустить Джокера на вечеринку!

## Получаем изображения динамически [[providing-images-with-dynamic-retrieval]]

> [!TIP]
> Код примера доступен в <a href="https://huggingface.co/agents-course/notebooks/blob/main/unit2/smolagents/vision_web_browser.py" target="_blank">этом Python-файле</a>.

Предыдущий подход полезен во многих ситуациях. Но если гостя нет в базе, нужны другие способы его опознать. Один из вариантов — динамически получать изображения и сведения из внешних источников, например искать подробности в интернете.

В этом случае изображения добавляются в память агента по ходу работы. Как мы знаем, агенты `smolagents` основаны на классе `MultiStepAgent`, который реализует абстракцию ReAct. Он работает в структурированном цикле, записывая переменные и знания на разных этапах:

1. **SystemPromptStep:** сохраняет системный промпт.
2. **TaskStep:** записывает пользовательский запрос и переданные входные данные.
3. **ActionStep:** фиксирует действия агента и их результаты.

Такая структура позволяет динамически включать визуальную информацию и адаптироваться к изменениям задачи. На знакомой нам схеме ниже показан этот процесс и связь шагов жизненного цикла агента. Во время просмотра веб-страниц агент может делать снимки экрана и сохранять их как `observation_images` в `ActionStep`.

![Динамическое получение изображений](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/smolagents-can-see/diagram_adding_vlms_smolagents.png)

Теперь понятно, зачем это нужно; соберём полный пример. Альфред хочет полностью контролировать проверку гостей, поэтому поиск подробностей через браузер — подходящее решение. Понадобится новый набор инструментов, а также Selenium и Helium для автоматизации браузера. С их помощью мы создадим агента, который исследует интернет, ищет сведения о потенциальном госте и получает данные для проверки. Установим необходимые инструменты:

```bash
pip install "smolagents[all]" helium selenium python-dotenv
```

Нам понадобятся специальные инструменты для работы в браузере: `search_item_ctrl_f`, `go_back` и `close_popups`. Они позволят агенту перемещаться по веб-страницам подобно человеку.

```python
@tool
def search_item_ctrl_f(text: str, nth_result: int = 1) -> str:
    """
    Searches for text on the current page via Ctrl + F and jumps to the nth occurrence.
    Args:
        text: The text to search for
        nth_result: Which occurrence to jump to (default: 1)
    """
    elements = driver.find_elements(By.XPATH, f"//*[contains(text(), '{text}')]")
    if nth_result > len(elements):
        raise Exception(f"Match n°{nth_result} not found (only {len(elements)} matches found)")
    result = f"Found {len(elements)} matches for '{text}'."
    elem = elements[nth_result - 1]
    driver.execute_script("arguments[0].scrollIntoView(true);", elem)
    result += f"Focused on element {nth_result} of {len(elements)}"
    return result


@tool
def go_back() -> None:
    """Goes back to previous page."""
    driver.back()


@tool
def close_popups() -> str:
    """
    Closes any visible modal or pop-up on the page. Use this to dismiss pop-up windows! This does not work on cookie consent banners.
    """
    webdriver.ActionChains(driver).send_keys(Keys.ESCAPE).perform()
```

Также нужна функция сохранения снимков экрана: для VLM-агента это важная часть решения задачи. Функция делает снимок и сохраняет его в `step_log.observations_images = [image.copy()]`, чтобы агент мог динамически накапливать и обрабатывать изображения во время навигации.

```python
def save_screenshot(step_log: ActionStep, agent: CodeAgent) -> None:
    sleep(1.0)  # Let JavaScript animations happen before taking the screenshot
    driver = helium.get_driver()
    current_step = step_log.step_number
    if driver is not None:
        for step_logs in agent.logs:  # Remove previous screenshots from logs for lean processing
            if isinstance(step_log, ActionStep) and step_log.step_number <= current_step - 2:
                step_logs.observations_images = None
        png_bytes = driver.get_screenshot_as_png()
        image = Image.open(BytesIO(png_bytes))
        print(f"Captured a browser screenshot: {image.size} pixels")
        step_log.observations_images = [image.copy()]  # Create a copy to ensure it persists, important!

    # Update observations with current URL
    url_info = f"Current url: {driver.current_url}"
    step_log.observations = url_info if step_logs.observations is None else step_log.observations + "\n" + url_info
    return
```

Эта функция передаётся агенту как `step_callback` и вызывается в конце каждого шага. Так агент может делать и сохранять снимки на протяжении всей работы.

Теперь создадим агента с визуальным восприятием для просмотра веб-страниц. Передадим ему наши инструменты и `DuckDuckGoSearchTool` для поиска информации. Этот инструмент поможет находить сведения, необходимые для проверки личности гостей по внешним признакам.

```python
from smolagents import CodeAgent, OpenAIServerModel, DuckDuckGoSearchTool
model = OpenAIServerModel(model_id="gpt-4o")

agent = CodeAgent(
    tools=[DuckDuckGoSearchTool(), go_back, close_popups, search_item_ctrl_f],
    model=model,
    additional_authorized_imports=["helium"],
    step_callbacks=[save_screenshot],
    max_steps=20,
    verbosity_level=2,
)
```

Всё готово: Альфред может проверять гостей и обоснованно решать, кого впустить на вечеринку:

```python
agent.run("""
I am Alfred, the butler of Wayne Manor, responsible for verifying the identity of guests at party. A superhero has arrived at the entrance claiming to be Wonder Woman, but I need to confirm if she is who she says she is.

Please search for images of Wonder Woman and generate a detailed visual description based on those images. Additionally, navigate to Wikipedia to gather key details about her appearance. With this information, I can determine whether to grant her access to the event.
""" + helium_instructions)
```

Обратите внимание, что в задачу включены `helium_instructions`. Этот специальный промпт управляет навигацией агента, помогая ему выполнять правильные шаги при просмотре веб-страниц.
