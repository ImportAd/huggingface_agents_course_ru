# Записываем действия в виде кода или структур JSON [[writing-actions-as-code-snippets-or-json-blobs]]

> [!TIP]
> Код урока доступен в <a href="https://huggingface.co/agents-course/notebooks/blob/main/unit2/smolagents/tool_calling_agents.ipynb" target="_blank">этом блокноте</a>, который можно запустить в Google Colab.

Tool Calling Agents — второй тип агентов в `smolagents`. В отличие от Code Agents, использующих фрагменты Python-кода, эти агенты **пользуются встроенной поддержкой вызова инструментов у провайдеров LLM** и формируют вызовы в виде **структур JSON**. Это стандартный подход OpenAI, Anthropic и многих других провайдеров.

Рассмотрим пример. Если Альфреду нужно найти услуги кейтеринга и идеи для вечеринки, `CodeAgent` сгенерирует и выполнит такой Python-код:

```python
for query in [
    "Best catering services in Gotham City", 
    "Party theme ideas for superheroes"
]:
    print(web_search(f"Search for: {query}"))
```

А `ToolCallingAgent` вместо этого создаст структуру JSON:

```python
[
    {"name": "web_search", "arguments": "Best catering services in Gotham City"},
    {"name": "web_search", "arguments": "Party theme ideas for superheroes"}
]
```

Затем система использует этот JSON для выполнения вызовов инструментов.

Хотя основной акцент в `smolagents` сделан на `CodeAgents`, поскольку [в целом они показывают лучшие результаты](https://huggingface.co/papers/2402.01030), `ToolCallingAgents` могут быть эффективны в простых системах, где не требуется работать с переменными или строить сложные вызовы инструментов.

![Действия в виде кода и JSON](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/transformers/code_vs_json_actions.png)

## Как работают Tool Calling Agents? [[how-do-tool-calling-agents-work]]

Tool Calling Agents следуют тому же многошаговому процессу, что и Code Agents; подробности — в [предыдущем уроке](./code_agents).

Главное различие — **в представлении действий**: вместо исполняемого кода они **генерируют JSON-объекты с именами инструментов и аргументами**. Затем система **разбирает эти инструкции** и выполняет соответствующие инструменты.

## Пример: запускаем Tool Calling Agent [[example-running-a-tool-calling-agent]]

Вернёмся к примеру, в котором Альфред начал подготовку к вечеринке, но теперь используем `ToolCallingAgent`, чтобы увидеть разницу. Мы создадим агента, который ищет информацию в интернете через DuckDuckGo, как и в примере с Code Agent. Меняется только тип агента — остальное берёт на себя фреймворк:

```python
from smolagents import ToolCallingAgent, WebSearchTool, InferenceClientModel

agent = ToolCallingAgent(tools=[WebSearchTool()], model=InferenceClientModel())

agent.run("Search for the best music recommendations for a party at the Wayne's mansion.")
```

В трассе работы агента вместо `Executing parsed code:` вы увидите примерно следующее:

```text
╭─────────────────────────────────────────────────────────────────────────────────────────────────────────────────╮
│ Calling tool: 'web_search' with arguments: {'query': "best music recommendations for a party at Wayne's         │
│ mansion"}                                                                                                       │
╰─────────────────────────────────────────────────────────────────────────────────────────────────────────────────╯
```  

Агент формирует структурированный вызов инструмента, который система обрабатывает для получения результата, а не выполняет код напрямую, как `CodeAgent`.

Теперь мы понимаем оба типа агентов и можем выбрать подходящий для своей задачи. Продолжим изучать `smolagents`, чтобы вечеринка Альфреда удалась! 🎉
