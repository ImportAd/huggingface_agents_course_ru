# Создаём RAG-инструмент для историй о гостях [[creating-a-rag-tool-for-guest-stories]]

Ваш верный агент Альфред готовится к самому роскошному приёму столетия. Чтобы вечер прошёл гладко, ему нужен быстрый доступ к актуальной информации о каждом госте. Поможем ему: создадим собственный инструмент Retrieval-Augmented Generation (RAG) на основе нашего датасета.

## Зачем RAG на приёме? [[why-rag-for-a-gala]]

Представьте Альфреда среди гостей: в любую минуту ему может понадобиться вспомнить конкретные сведения о человеке. Обычной LLM будет непросто, потому что:

1. Список гостей относится именно к вашему мероприятию и отсутствует в обучающих данных модели.
2. Сведения о гостях могут часто меняться и обновляться.
3. Альфреду нужны точные данные, например адреса электронной почты.

Вот где полезен RAG! Объединив поисковую систему с LLM, мы дадим Альфреду доступ к точной и актуальной информации по мере необходимости.

> [!TIP]
> Вы можете использовать любой фреймворк из курса. Выберите подходящий вариант на вкладках с кодом.

### Шаг 2. Создаём инструмент поиска [[step-2-create-the-retriever-tool]]

Создадим собственный инструмент, которым Альфред будет пользоваться для поиска сведений о гостях.

<hfoptions id="agents-frameworks">
<hfoption id="smolagents">

Для инструмента поиска используем `BM25Retriever` из модуля `langchain_community.retrievers`.

> [!TIP]
> <code>BM25Retriever</code> — хороший отправной вариант. Для более продвинутого семантического поиска можно рассмотреть решения на основе эмбеддингов, например из <a href="https://www.sbert.net/">sentence-transformers</a>.

```python
from smolagents import Tool
from langchain_community.retrievers import BM25Retriever

class GuestInfoRetrieverTool(Tool):
    name = "guest_info_retriever"
    description = "Retrieves detailed information about gala guests based on their name or relation."
    inputs = {
        "query": {
            "type": "string",
            "description": "The name or relation of the guest you want information about."
        }
    }
    output_type = "string"

    def __init__(self, docs):
        self.is_initialized = False
        self.retriever = BM25Retriever.from_documents(docs)

    def forward(self, query: str):
        results = self.retriever.invoke(query)
        if results:
            return "\n\n".join([doc.page_content for doc in results[:3]])
        else:
            return "No matching guest information found."

# Initialize the tool
guest_info_tool = GuestInfoRetrieverTool(docs)
```

Разберём устройство инструмента:
- `name` и `description` помогают агенту понять, когда и как его использовать.
- `inputs` описывает ожидаемые параметры — здесь это поисковый запрос.
- `BM25Retriever` использует эффективный алгоритм текстового поиска, которому не нужны эмбеддинги.
- Метод `forward` обрабатывает запрос и возвращает наиболее подходящие сведения о гостях.

```python
from typing import TypedDict, Annotated
from langgraph.graph.message import add_messages
from langchain_core.messages import AnyMessage, HumanMessage, AIMessage
from langgraph.prebuilt import ToolNode
from langgraph.graph import START, StateGraph
from langgraph.prebuilt import tools_condition
from langchain_huggingface import HuggingFaceEndpoint, ChatHuggingFace

# Generate the chat interface, including the tools
llm = HuggingFaceEndpoint(
    repo_id="Qwen/Qwen2.5-Coder-32B-Instruct",
    huggingfacehub_api_token=HUGGINGFACEHUB_API_TOKEN,
)

chat = ChatHuggingFace(llm=llm, verbose=True)
tools = [guest_info_tool]
chat_with_tools = chat.bind_tools(tools)

# Generate the AgentState and Agent graph
class AgentState(TypedDict):
    messages: Annotated[list[AnyMessage], add_messages]

def assistant(state: AgentState):
    return {
        "messages": [chat_with_tools.invoke(state["messages"])],
    }

## The graph
builder = StateGraph(AgentState)

# Define nodes: these do the work
builder.add_node("assistant", assistant)
builder.add_node("tools", ToolNode(tools))

# Define edges: these determine how the control flow moves
builder.add_edge(START, "assistant")
builder.add_conditional_edges(
    "assistant",
    # If the latest message requires a tool, route to tools
    # Otherwise, provide a direct response
    tools_condition,
)
builder.add_edge("tools", "assistant")
alfred = builder.compile()

messages = [HumanMessage(content="Tell me about our guest named 'Lady Ada Lovelace'.")]
response = alfred.invoke({"messages": messages})

print("🎩 Alfred's Response:")
print(response['messages'][-1].content)
```

Ожидаемый вывод:

```
🎩 Alfred's Response:
Lady Ada Lovelace is an esteemed mathematician and pioneer in computing, often celebrated as the first computer programmer due to her work on Charles Babbage's Analytical Engine.
```

На этом заключительном шаге мы:
- Инициализируем модель Hugging Face через `HuggingFaceEndpoint`, создаём интерфейс чата и подключаем инструменты.
- Создаём Альфреда как `StateGraph`, соединяющий два узла — `assistant` и `tools` — ребром.
- Просим его найти сведения о гостье по имени «Lady Ada Lovelace» — леди Аде Лавлейс.

## Развиваем решение дальше [[taking-it-further]]

Теперь Альфред умеет искать информацию о гостях. Подумайте, как улучшить систему:

1. **Усовершенствовать поиск**, используя более сложный подход, например [sentence-transformers](https://www.sbert.net/).
2. **Добавить память разговора**, чтобы Альфред помнил предыдущие взаимодействия.
3. **Подключить веб-поиск** для получения свежих сведений о незнакомых гостях.
4. **Объединить несколько индексов**, чтобы получать более полную информацию из проверенных источников.

Теперь у Альфреда есть всё необходимое, чтобы без труда отвечать на вопросы о гостях и сделать ваш приём самым изысканным и приятным событием столетия!
